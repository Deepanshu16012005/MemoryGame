# Memory Blink Game

A browser-based memory game where players need to remember and repeat sequences of blinking colored cards.

## Game Description

Memory Blink is an engaging memory game that tests your ability to recall sequences. The game features four colored cards (red, blue, green, and yellow) that blink in a specific pattern. Players must replicate the sequence correctly to advance to the next level.

## Features

- Progressive difficulty: Each level adds one more step to the sequence
- Four distinct colored cards (red, blue, green, yellow)
- High score tracking using local storage
- Responsive design that works on both desktop and mobile
- Visual feedback with card animations
- High score management system

## How to Play

1. Click the "Start" button to begin the game
2. Watch the sequence of blinking cards carefully
3. Click the cards in the same order as they blinked
4. If successful, you'll advance to the next level
5. If you make a mistake, the game ends and your score is recorded

## Technical Details

The game is built using:
- HTML5
- CSS3 with animations
- Vanilla JavaScript
- Local Storage for high score persistence

## File Structure

- `index.html` - Main game interface
- `highscore.html` - High score display and management
- `style.css` - Game styling and animations
- `script.js` - Main game logic
- `data.js` - High score handling

## Setup

1. Clone the repository
2. Open `index.html` in a modern web browser
3. No additional setup or dependencies required
